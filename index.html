Dominó

Duplo-seis para dois jogadores no mesmo dispositivo

Como funciona

  • São 28 peças. Cada jogador recebe 7 e as outras 14 ficam no monte.
  • Começa quem tiver a maior peça dupla, e ela abre a partida.
  • Jogue uma peça que tenha o mesmo número de uma das pontas da mesa.
  • Sem peça para jogar, compre do monte. Com o monte vazio, passe a vez.
  • Vence quem ficar sem peças. Se o jogo bloquear, vence quem tiver menos pontos na mão.

Passe o dispositivo para essa pessoa. As peças só aparecem depois do clique.
